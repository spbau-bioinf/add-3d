## На этом занятии вы:
{: .section__title}

- Прочитаете файл STL (от stereolithography, стереолитография) собственной программой на Python и увидите, что в нем записано: нормали, вершины и больше ничего, даже единиц измерения.
- Превратите «треугольный суп» в индексированную сетку и проверите ее формулой Эйлера.
- Найдете дыры и сингулярные ребра, посчитав, сколько граней примыкает к каждому ребру.
- Проверите согласованность ориентации граней, вычислите объем модели и исправите перевернутые грани.
- Найдете лишние оболочки и вырожденные грани и очистите от них модель.
- Сравните свои проверки с библиотекой [trimesh](https://trimesh.org/) для работы с сетками на Python, упростите сетку с контролем отклонения и компенсируете усадку после сглаживания.
{: .outcomes}

</section>

<section class="section" markdown="1">

## Зачем нужен этот материал
{: .visually-hidden}

Между моделью и G-кодом стоит сетка из треугольников. Если в ней есть дыра, перевернутая грань или лишняя оболочка, слайсеру приходится угадывать, где тело, и ошибка проявится уже в напечатанной детали. Проверять сетку глазами бесполезно: у модели кости тысячи граней, а дыра может занимать одну из них. Три из четырех главных дефектов находятся простым подсчетом по таблице связности, и на этом занятии вы напишете такие проверки сами.
{: .lead}

<aside class="callout callout--important" markdown="1">

Подготовка компьютера до занятия
{: .callout__title}

Страницы task 2-1 … task 2-5 используют только стандартную библиотеку Python 3.11 или новее. Для task 2-6 и task 2-7 нужна библиотека trimesh с дополнительными пакетами. Скачайте файл [requirements.txt](../assets/files/requirements.txt) и установите все заранее одной командой в терминале из папки с этим файлом:

```text
pip install -r requirements.txt
```

В файле указаны версии, на которых проверены все числа занятия (trimesh 5.1.0). С другой версией примеры task 2-6 могут дать немного другие числа. Проверка: команда `python -c "import trimesh; print(trimesh.__version__)"` должна напечатать `5.1.0`. Если установка не удалась (чаще всего из-за пакетов `rtree` или `fast-simplification`), сообщите преподавателю до занятия и работайте на компьютере класса с готовым окружением.

## Как работать с материалом
{: .section__title}

- Проходите страницы строго по порядку: каждая следующая опирается на предыдущие. Страница [task 2-0](task_2-0.html) теоретическая, заданий для сдачи в ней нет.
- Все файлы занятия создавайте в одной рабочей папке, например `mesh_work`. Модели для заданий скачиваются со страниц, где они нужны; кладите их в ту же папку, иначе программы их не найдут.
- Программы сохраняйте в отдельные файлы с именами из условия, например `task_2-3_1.py`. Если в задании нужен ответ словами, запишите его комментарием в конце программы.
- Числа и строки вывода должны совпадать с «Требуемым выводом», если в условии прямо не сказано иное. Иное разрешено в трех местах: порядок дыр на task 2-3, тысячные доли отклонения на task 2-6 и последний знак объема (±0,1 мм³ для объемов с одним знаком после запятой, ±0,01 мм³ для объемов с двумя).
- Начиная с [task 2-3](task_2-3.html), вы собираете функции проверки в один файл `mesh_checks.py` в рабочей папке. Имена и аргументы функций заданы в условиях; программы страниц импортируют их из этого файла. На [task 2-7](task_2-7.html) из этих функций собирается итоговая программа.
- Программы проверяются запуском на другой модели, например на `bone_a.stl` или на модели, измененной в просмотрщике, и вопросом по любой строке кода. Программа, которая печатает готовые числа без вычислений, и программа, которую вы не можете объяснить, не засчитываются.
- На страницах task 2-1 … task 2-5 у каждой программы есть окно запуска Python: код выполняется прямо в браузере, модели и модули страницы в нем уже есть. Окно сравнивает вывод с требуемым. Файл для сдачи все равно сохраняйте у себя. Программы task 2-6 и task 2-7 используют trimesh и запускаются только на вашем компьютере.
- Вопросы на понимание оформлены мини-тестами. После верных ответов тест собирает комментарий; скопируйте его в конец программы, к которой относится вопрос.
- Просмотрщик сеток на страницах служит проверкой: сначала напишите и запустите программу, потом сверьте результат в просмотрщике.
- В конце каждой страницы с заданиями есть блок «Затем»: он говорит, в какую папку переместить файлы. Личная папка у вас уже есть с первого занятия; для этого занятия внутри нее появится папка `pipeline_2`.

<aside class="callout callout--hint" markdown="1">

Где посмотреть сетку
{: .callout__title}

Это занятие о проверке подсчетом, но модель полезно и увидеть. На сайте курса есть [просмотрщик сеток](../mesh-viewer.html): он подсвечивает края, сингулярные ребра, перевернутые грани и лишние оболочки. Кроме него STL открывают бесплатные программы и сервисы:

- [Online 3D Viewer](https://3dviewer.net/): просмотр STL, OBJ (формат компании Wavefront), PLY (Polygon File Format) и 3MF (3D Manufacturing Format) в браузере;
- [MeshLab](https://www.meshlab.net/): программа для обработки сеток, умеет подсвечивать края и немногообразные ребра;
- любой слайсер, например [PrusaSlicer](https://www.prusa3d.com/page/prusaslicer_424/) или [UltiMaker Cura](https://ultimaker.com/software/ultimaker-cura/), при открытии STL сообщает о найденных ошибках сетки.

Программы по-разному понимают поврежденные файлы. При расхождении ориентируйтесь на числа из заданий.

</aside>
