## Что это
{: .section__title}

Учебный слайсер повторяет в браузере то, что разобрано на занятии: режет модель на слои, строит в каждом слое периметры и заполнение и записывает G-код в том же диалекте, что `gen.py` из [task 1-4](task_1/task_1-4.html). Результат открывается в просмотрщике ниже и разбирается программой `stats.py`. Код слайсера открыт: `assets/js/slicer-core.js`, около 150 строк с комментариями.

- Загрузите модель: кронштейн из [task 1-6](task_1/task_1-6.html) кнопкой или свой файл STL (двоичный или текстовый).
- Задайте высоту слоя, ширину дорожки, число периметров, плотность заполнения и число сплошных слоев. Модель ставится на платформу по центру стола автоматически.
- Нажмите «Нарезать». Статистика считается тем же разбором, что в просмотрщике; G-код можно скачать и использовать в заданиях.

<aside class="callout callout--warning" markdown="1">

Ограничения
{: .callout__title}

- Нет поддержек, выбора ориентации и ретракта: модель печатается как загружена, свесы остаются без опоры.
- Заполнение только прямолинейное, с чередованием 0° и 90° по слоям; первые и последние слои сплошные. Скорости две: 1200 мм/мин для периметров и 1800 мм/мин для заполнения.
- Подача считается по балансу объема для нити 1,75 мм, без учета материала и температуры; команды нагрева взяты из примера task 1-1.
- Модели с сотнями тысяч треугольников режутся медленно: слайсер не оптимизирован, он написан для чтения.

Поэтому числа учебного слайсера и PrusaSlicer различаются. Для сравнения вариантов одной модели между собой этого достаточно; для печати на принтере нужен настоящий слайсер.

</aside>

## Как это устроено
{: .section__title}

1. **Сечение.** Для каждой высоты *Z* = *H* / 2 + *k* · *H* берутся треугольники STL, которые пересекает плоскость; по двум ребрам каждого вычисляются точки пересечения, отрезки между ними связываются в замкнутые контуры (как в [task 1-0](task_1/task_1-0.html), раздел 3).
1. **Многоугольники.** Контуры объединяются по правилу «чет-нечет»: внешние контуры и отверстия различаются по направлению обхода. Для этого используется библиотека [Clipper](http://www.angusj.com/clipper2/) — открытая библиотека операций над многоугольниками.
1. **Периметры.** Контур смещается внутрь на *W* / 2 (ось первой дорожки), затем еще на *W* для каждого следующего периметра ([task 1-3](task_1/task_1-3.html), раздел 1).
1. **Заполнение.** Внутри последнего периметра проводятся линии с шагом *W* / плотность, обрезанные областью заполнения с перекрытием *W* / 2 ([task 1-4](task_1/task_1-4.html), раздел 2); направление чередуется по слоям.
1. **G-код.** Подготовка, относительная подача `M83`, подача по формуле [task 1-2](task_1/task_1-2.html).
