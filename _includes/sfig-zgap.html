{%- comment -%} Схема task 5-3, раздел 3: верхний зазор поддержки по оси Z (support_top_z_distance) при высоте слоя 0,2 мм. Значения списка — как в Bambu Studio 2.9.2.62: 0 (soluble), 0.1 (semi-detachable), 0.2 (detachable). Внутри нет пустых строк. {%- endcomment -%}
Вид сбоку при высоте слоя 0,2 мм, 1 мм = 60 пикселей. Сверху — нижние слои нависающей части детали, снизу — поддержка; ее верхние слои (контактный слой, интерфейс) уложены плотно. Между ними — верхний зазор по оси Z. При зазоре 0 деталь лежит прямо на поддержке: так печатают растворимой поддержкой из другого материала. Чем больше зазор, тем легче отделить поддержку и тем хуже нижняя поверхность детали: ее первый слой над зазором частично висит в воздухе.
