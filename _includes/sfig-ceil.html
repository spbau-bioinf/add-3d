{%- comment -%} Схема task 3-1, раздел 3: число слоев N = ⌈H / τ⌉ и неполный верхний слой. Внутри нет пустых строк. {%- endcomment -%}
Разрез детали сбоку, высоты увеличены. Черная рамка — модель высотой H, зеленые полосы — слои толщиной τ, точки — плоскости слоев на их серединах (z = (i + 0,5) · τ, раздел 3 task 3-0). Если H не делится на τ нацело, над последним полным слоем остается часть модели тоньше слоя. Формула N = ⌈H / τ⌉ отводит под нее еще один слой той же толщины — неполный верхний слой, он выделен желтым. Если остаток больше половины слоя (H = 2,0 мм, τ = 0,3 мм: остаток 0,2 мм), плоскость этого слоя проходит через модель, у слоя есть контур, и он печатается; деталь выходит выше модели на 0,1 мм. Если остаток меньше половины (H = 1,9 мм: остаток 0,1 мм), плоскость оказывается выше модели и сечение пустое: такой слой ничего не печатает, хотя формула его считает.
