## О странице
{: .section__title}

Справка к практике 5. Глоссарий прочитайте до первой практики по данной теме: в нем слова, которые встречаются в шагах. ## <span class="subsection__num">1.</span> Глоссарий
{: .subsection__title}

| Термин | Что значит |
|---|---|
| ЛКМ, ПКМ | левая и правая кнопка мыши; «нажмите ЛКМ» — одно нажатие левой кнопкой |
| слайсер | программа, которая режет модель на слои и строит траекторию сопла; на этом занятии — Bambu Studio 2.9.2.62 |
| Bambu Studio | слайсер компании Bambu Lab для ее принтеров, основан на PrusaSlicer; исходный код и выпуски — [github.com/bambulab/BambuStudio](https://github.com/bambulab/BambuStudio) |
| Bambu Lab A1 mini | принтер лаборатории: экструзионный, стол 180 × 180 мм, высота печати 180 мм, сопло 0,4 мм |
| пластина / plate | съемный лист стола, на который печатают; у нас текстурированная PEI пластина. В программе пластиной называется и стол со всеми моделями на нем |
| профиль | набор значений настроек; в Bambu Studio их три: принтера («Принтер / Printer»), материала («Филамент / Filament»), процесса печати («Процесс / Process») |
| филамент | пластиковая нить диаметром 1,75 мм, из которой печатают; у нас Bambu PLA Matte |
| PLA | polylactic acid, полилактид — основной пластик курса; Matte — матовый вариант, профиль Bambu PLA Matte печатает при 220 °C |
| нарезка / slicing | разбиение модели на слои и построение траектории; кнопка «Нарезать пластину / Slice plate» |
| предпросмотр / preview | вкладка, где после нарезки виден каждый слой, время печати и расход нити |
| 3MF | 3D Manufacturing Format — формат файла-архива для 3D-печати: кроме сетки модели хранит настройки; в нем Bambu Studio сохраняет и проект, и нарезанный файл |
| проект `.3mf` | файл Bambu Studio с моделями, их положением на столе и всеми настройками; «Сохранить проект / Save project» |
| нарезанный файл `.gcode.3mf` | файл с G-кодом для принтера, расчетным временем и массой нити; «Экспортировать нарезанный файл пластины / Export plate sliced file» |
| стенка / wall | замкнутые дорожки по контуру слоя; в PrusaSlicer — периметр |
| разреженное заполнение / sparse infill | решетка внутри стенок; плотность в процентах |
| оболочка / shell | сплошные слои сверху и снизу детали, закрывающие заполнение |
| поддержка / support | временная конструкция под нависаниями, которую удаляют после печати; обычная — колонны, древовидная — ветки |
| пороговый угол / threshold angle | поддержка строится под нависаниями, угол которых к горизонтали меньше порога; в профиле 30° |
| интерфейс поддержки | плотные верхние слои поддержки, на которые ложится деталь |
| верхний зазор по Z / top Z distance | промежуток по высоте между поддержкой и деталью, чтобы поддержку можно было отделить |
| кайма / brim | дорожки первого слоя вокруг детали, увеличивающие площадь касания со столом |
| шов / seam | место, где начинается и заканчивается внешняя стенка слоя |
| мост / bridge | горизонтальный участок, натянутый между двумя опорами без поддержки под ним |
| консоль | выступ, закрепленный с одной стороны и висящий с другой |
| «слоновья нога» | расширение первого слоя, прижатого к столу |
| объемная скорость | сколько кубических миллиметров пластика сопло выдавливает за секунду; у Bambu PLA Matte предел 22 мм³/с |
| ориентация | положение модели на столе: что внизу и что по высоте печати |
| анизотропия | разная прочность детали вдоль дорожек и поперек слоев ([task 5-5](task_5-5.html)) |
| концентратор напряжений | место, где напряжения под нагрузкой выше, чем в остальном сечении: надрез, острый угол, впадина между слоями ([task 5-5](task_5-5.html)) |
| литой образец | образец из того же пластика, отлитый под давлением в форму: в нем нет дорожек и швов, поэтому с ним сравнивают прочность напечатанных образцов ([task 5-5](task_5-5.html)) |
| таймлапс / timelapse | ускоренное видео печати из кадров камеры принтера; на занятии запись выключена, но время на нее программа закладывает в расчет нарезки ([task 5-1](task_5-1.html)) |
| масштаб 2 : 1 | увеличение модели в 2 раза по всем осям; задается в слайсере, файл модели не меняется |
| общая учетная запись | учетная запись Bambu одна на группу; через нее задания уходят на принтер по облаку |
| позвонок: тело, дужка, отростки | тело — массивная передняя часть позвонка, несущая нагрузку; дужка с остистым и поперечными отростками — задняя часть, к отросткам крепятся мышцы и связки; рисунок — на [task 5-1](task_5-1.html) |
| замыкательная пластинка | верхняя или нижняя поверхность тела позвонка, обращенная к межпозвонковому диску; на нее опирается позвонок в положении по правилу ([task 5-1](task_5-1.html)) |
| положение по правилу | исходное положение позвонка на столе: он стоит так же, как в позвоночнике стоящего человека, тело опирается на замыкательную пластинку ([task 5-1](task_5-1.html), раздел 4) |
| Th12, L1–L5 | двенадцатый грудной (thoracic) и пять поясничных (lumbar) позвонков сверху вниз; на этом занятии кейдж кладут рядом с промежутком между L4 и L5 |
| КТ | компьютерная томография: послойные рентгеновские снимки, по которым получены модели позвонков |
| автоориентация / auto orient | кнопка на панели инструментов: программа сама поворачивает модель на столе |
| бокорезы | кусачки с режущими кромками сбоку; ими удаляют поддержки ([task 5-9](task_5-9.html)) |

## <span class="subsection__num">2.</span> PrusaSlicer и Bambu Studio: одни и те же настройки
{: .subsection__title}

Bambu Studio основан на PrusaSlicer, и многие настройки совпадают по смыслу, но называются иначе. Названия Bambu Studio даны парами: русский интерфейс / английский.

| PrusaSlicer (практики 1–3) | Bambu Studio | Разобрано |
|---|---|---|
| Print Settings, Filament Settings, Printer Settings | Процесс / Process, Филамент / Filament, Принтер / Printer | [task 5-3](task_5-3.html) |
| Plater | Подготовка / Prepare | [task 5-1](task_5-1.html) |
| Preview | Предпросмотр / Preview | [task 5-2](task_5-2.html) |
| Layer height | Высота слоя / Layer height | [task 5-3](task_5-3.html) |
| Perimeters | Контуры стенок / Wall loops | [task 5-3](task_5-3.html) |
| Fill density, Fill pattern | Плотность разреженного заполнения / Sparse infill density, Тип внутреннего заполнения / Sparse infill pattern | [task 5-3](task_5-3.html) |
| Solid layers: Top, Bottom | Толщина оболочки сверху / Top shell layers, Слои нижней оболочки / Bottom shell layers | [task 5-7](task_5-7.html) |
| Generate support material | Включить поддержку / Enable support | [task 5-3](task_5-3.html) |
| Overhang threshold | Пороговый угол / Threshold angle | [task 5-3](task_5-3.html) |
| Contact Z distance | Верхний зазор по оси Z / Top Z distance | [task 5-3](task_5-3.html) |
| Brim width | Тип каймы / Brim type, Ширина каймы / Brim width | [task 5-3](task_5-3.html) |
| Seam position | Положение шва / Seam position | [task 5-7](task_5-7.html) |
| Ironing | Тип разглаживания / Ironing Type | [task 5-7](task_5-7.html) |
| Elephant foot compensation | Компенсация эффекта «слоновьей ноги» / Elephant foot compensation | [task 5-7](task_5-7.html) |
| Max volumetric speed | Максимальная объемная скорость / Max volumetric speed | [task 5-3](task_5-3.html) |
| Export G-code | Экспортировать нарезанный файл пластины / Export plate sliced file | [task 5-2](task_5-2.html) |

## <span class="subsection__num">3.</span> Проблемы и решения
{: .subsection__title}

| Что случилось | Вероятная причина | Что сделать |
|---|---|---|
| программа предлагает обновиться | вышла новая версия | откажитесь: на курсе одна версия, 2.9.2.62 |
| вход в учетную запись просит код | вход с нового компьютера | код приходит на почту учетной записи: скажите преподавателю |
| принтер не виден на вкладке «Устройство» | нет интернета или не выполнен вход | проверьте вход и сеть; если облако недоступно, отправку выполняет преподаватель |
| принтер занят | печатается чужое задание | дождитесь окончания; чужое задание не отменяйте |
| модель выходит за пределы стола | кейдж после масштаба или модель не на столе | проверьте масштаб и нажмите «Расставить все объекты / Arrange all objects» |
| кейдж маленький, 22 × 9 мм | масштаб 2 : 1 не задан | задайте масштаб 200 % ([task 5-6](task_5-6.html)) |
| время и масса заметно отличаются от чисел на странице | другая модель, другой профиль или другая версия программы | проверьте принтер, материал и профиль процесса; сравните габариты модели с эталоном |
| деталь отлипает от стола | жирный лист, узкая опора | протрите лист изопропиловым спиртом, не трогайте его пальцами; включите кайму |
| поддержка не отделяется | мал верхний зазор по Z | верните зазор 0,2 мм (detachable) |
| сквозь верх видна решетка | мало верхних слоев | проверьте верхние слои и толщину оболочки ([task 5-7](task_5-7.html)) |
| самопроверка не принимает файл | открыт проект без нарезки, не тот файл или не та деталь | проверьте и `.3mf`, и `.gcode.3mf` на странице [проверки файлов Bambu Studio](../bambu-check.html) и выберите нужную деталь |
| время позвонка на 2–4 % меньше, чем в таблице эталонов, масса та же | проект сохранен и открыт заново: программа режет его немного иначе, чем STL сразу после импорта (у L4 1 ч 45 мин против 1 ч 49 мин) | ничего: время на оценку не влияет; в «предскажи и проверь» сравнивайте нарезки одной копии ([task 5-4](task_5-4.html)) |
| числа в поле ввелись неверно, например 6 вместо 0,6 | дробное число введено с точкой | вводите дробные числа с запятой: `0,6` |
| поле «Вращение (абсолютное)» показывает странные углы | программа пересчитывает углы поворота по-своему | положение проверяйте по высоте в строке «Размер» инструмента «Масштаб [S]» |
| файл позвонка виден в `git status` или в `git ls-files` | в папке нет `.gitignore` из архива, файл позвонка переименован или попал в коммит раньше, чем появился `.gitignore` | раздел 2 [task 5-1](task_5-1.html) и раздел 3 [task 5-8](task_5-8.html) |
| проверка нарезанного файла кейджа пишет, что высота печати не подходит | нарезан не кейдж, масштаб не 200 % или кейдж повернут не на 90° | проверьте «Размер» в инструменте «Масштаб [S]» ([task 5-6](task_5-6.html), разделы 1 и 2), нарежьте и сохраните оба файла заново |
| проверка пишет, что подпись не лежит на кейдже | текст остался рядом с кейджем | перетащите желтый квадрат текста на боковую стенку ([task 5-6](task_5-6.html), раздел 4) |
{: .table-mid}

Практика проверена в Windows 11. В macOS вместо Ctrl обычно используется Cmd; работа программы в macOS на курсе не проверялась.
